# Hackathon findings

Gathered Oct 20, 2026 from search results; the official event page couldn't be opened directly. Re-check against the official rules once they're posted.

## Status

- Application **approved** (Oct 20, 2026).
- Official rules: not published yet. Cerebral Valley and dev.meta.ai say they'll be posted before the hackathon begins on Oct 26.

## Dates

- Applications close Oct 25, 11:59 PM ET, or earlier if all 20,000 spots fill.
- Build window: Oct 26 – Nov 4, 2026 (10 days).
- Submissions: reportedly due Nov 5, 2026 UTC (Internshala lists 6:30 AM IST); sources disagree, so plan to finish on Nov 4.
- Judging: Nov 5–9 per Internshala.

## Format

- Two tracks: indie developer and startup. We're entering Indie, solo.
- Judging: impact 30%, creative use of Meta tooling 25%, demo 25%, technical depth 20%.
- Eligibility excludes Meta and Cerebral Valley employees, government-affiliated people, their immediate families, and some sanctioned countries.

## Meta Model API

- Muse Spark 1.1 opened to developers through the Model API in July 2026, at first for US developers.
- New sign-ups get $20 in free credits; one source says hackathon participants get $150.
- After credits: $1.25 per million input tokens, $4.25 per million output tokens.
- Meta's launch demo showed it building a web app, screenshotting it, spotting problems and testing fixes, which is close to what the explorer needs.
